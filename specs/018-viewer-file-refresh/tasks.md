# 任务分解：Electron 查看器窗口随源文件更新自动刷新

执行顺序按依赖排列：先落契约与 Core 监听，再接宿主路由与 Electron 控制器，然后接三类
查看器刷新通道，最后补测试、文档与全量验证。去抖周期统一为 50ms。需求与验收见
[spec.md](spec.md)，技术方案见 [plan.md](plan.md)。
