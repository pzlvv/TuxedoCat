# 缺陷：重启重连后标签页灯不全——绿不武装、蓝黄聚合丢失

后台运行 / 应用重启后的重开场景里，标签页的三色灯条（蓝运行 / 黄等待 / 绿完成）
依赖两份「晚到」的输入：会话运行时快照（认领重放 / 列表装载）与会话归属索引
（`syncSessionWorkspaceIndex` 只刷活动目录的列表快照）。快照与索引的到达顺序
不定，标签页聚合与武装只跑一次、错过不补——表现：对话行绿灯亮了标签页不亮
（用户实测），蓝色运行灯同理依赖时序侥幸。

## 现状

- **绿色（未读完成）**：补武装（`backfillCompletionAttention`）沿用了在线差分的
  「完成时该标签页未激活才武装」规则——离场完成的完成时刻用户**完全缺席**，
  重开后重开的工作区标签页往往恰是激活态（重新打开 / 恢复的活动项），标签页灯
  被这条规则永远跳过；对话行绿灯亮了标签页不亮（US-65 验收第 4 条的两处武装面
  只兑现一处）。归属解析还有第二个缺口：多标签下已完成会话归属非活动目录时，
  列表后到、`resolveSessionWorkspaceRef` 解析不出，标签页灯挂不上。
- **蓝色（运行）/ 黄色（等待）**：标签页聚合 `collectWorkspaceActivity()` 在
  状态流每次推送时执行一次（`setStatusListener` 唯一触发点）。重启认领场景里
  重放的运行时快照**早于**对话列表到达（daemon 在 openWorkspace 应答里就重放，
  列表请求要等 ready 后才发出）——聚合时归属索引为空，非 idle 会话解析不出
  归属被丢弃；列表到达补齐索引后没有任何重聚合触发点，静默运行的在跑任务
  （工具执行期没有新快照）标签页灯一直不亮。US-65 的 e2e 探针曾断言过标签页
  运行灯，通过属时序侥幸（可用性翻转的内嵌重聚合恰好落在列表之后）。

## 期望

- **绿色**：离场完成的标签页灯脱离「完成时未激活」规则——补武装的会话只要
  归属可解析，标签页即武装（激活中的也算未读）；在线差分的规则不变。
- **蓝 / 黄**：对话列表到达（归属索引补齐）时重推一次标签页聚合
  （`syncTitlebarActivity`）——快照早于列表到达的窗口被列表到达的补聚合填平；
  状态流本身的推送触发点不变。
- 归属索引晚到的会话（非活动目录的列表后到）在索引补齐后的下一次列表到达
  补挂标签页灯：主进程记录补武装来源的会话集合，列表到达出口对其中仍未读的
  会话重试归属解析（绿）并随全量重聚合覆盖（蓝 / 黄）。
- 会话被阅读 / 从快照消失 / 工作区关闭时，补武装来源记录同步清理。

## 不变量

- 在线差分的武装规则完全不变（完成时未激活才武装标签页；激活中的标签页视为
  已读，切走再切回不补亮）。
- 对话行武装、阅读清除、护栏（`completionsReadInRun`）语义不变。
- agent 创建的会话在补武装里保持安静（specs/025 FR-003）。
- 托盘状态点 / 睡眠阻断 / 关闭确认直接读状态流或按需实时聚合，本缺陷的修复
  不改变它们的语义。

## 回归测试

- **RT-1**：补武装纯函数按计数 > 0 与 creator 过滤产出会话名单（签名收敛为
  只返回会话，标签页归属移交调用方；落点：
  `src/test/completionAttention.test.ts`）。
- **RT-2**：e2e——重启重开后对话行与标签页**同时**亮绿色未读完成灯（落点：
  `e2e/electron/completionAfterRestart.spec.ts`，断言标签页 `activity-completed`）。
- **RT-3**：蓝色运行灯的认领重开断言（既有用例的探针保留并转正，落点：
  `e2e/electron/remoteTaskSurvival.spec.ts` US-65 认领用例）；蓝色 / 黄色与绿色
  共用列表到达的重聚合触发点。
