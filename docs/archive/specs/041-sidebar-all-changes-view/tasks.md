# 任务分解：文件资源管理器的「全部变更」视图

执行顺序：取数参数化先行（T001），三态模式与存储迁移（T002）依赖它，第三个按钮
（T003）与打开 / 哨兵接线（T004）合起来才可用；文档（T005）、e2e（T006）、全量回归
（T007）收尾。与 specs/040 共用 `electron/main.ts` 与 `electron/fileOpen.ts` 的接线，
两个 spec 的宿主侧任务同批实施、同一次提交。需求口径见 [spec.md](spec.md)，技术方案见
[plan.md](plan.md)。
