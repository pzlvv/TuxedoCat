执行顺序：先补节点身份载体（T001，独立提交、行为不变），再叠 core 的截断与文件回滚

e2e（T007）、全量回归（T008）收尾。需求口径见 [spec.md](spec.md)，技术方案见
[plan.md](plan.md)。
