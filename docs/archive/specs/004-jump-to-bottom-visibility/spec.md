# 改动规格：跳到底部按钮显示触发与交互调整

收紧 [US-47 跳到底部](../../docs/features/user-stories.md#us-47-跳到底部)按钮的显示触发：
从「不在底部 && 用户主动滚离」改为「一次向下的滚动手势累计位移超过消息区可视高度 1/3
且当前不在底部」，且触发源仅限滚轮（滚动条拖动、键盘、触摸产生的滚动一律不触发，
拖动开始时已显示的按钮隐藏）；按钮位置从底部居中移到右下角（留小边距）；
显隐切换加快速淡入淡出；用户向上滚动（任意幅度）时已显示的按钮立即隐藏。
自动滚动抑制（`userScrolledAway`）机制本身不变——本 spec
只改按钮显隐信号，二者解耦：滚轮上滚不再让按钮出现，但滚离抑制保持原样。

## 用户场景与验收标准

- 场景 1：按钮显示触发条件收紧
  - **AC-1**（FR-001）：GIVEN 消息列表停在底部且无滚轮输入（含流式内容增长、工具输出展开造成的瞬时离底） WHEN 消息区持续更新 THEN 按钮始终不显示
  - **AC-2**（FR-001）：GIVEN 用户不在底部 WHEN 消息区内一次向下滚动手势的累计滚动位移超过消息区可视高度的 1/3 THEN 按钮淡入显示
  - **AC-3**（FR-001）：GIVEN 用户不在底部 WHEN 一次向下滚动手势的累计滚动位移不超过 1/3（如单格慢滚） THEN 按钮不显示
  - **AC-4**（FR-001）：GIVEN 按钮因达标手势显示 WHEN 用户滚回底部（滚到底、End 键或点击按钮） THEN 按钮淡出隐藏
- 场景 2：触发源仅限滚轮
  - **AC-5**（FR-004）：GIVEN 用户不在底部 WHEN 用键盘 PageDown / 空格 / 方向键向下滚动 THEN 按钮不显示
  - **AC-6**（FR-004）：GIVEN 按钮已显示 WHEN 用户开始拖动滚动条 THEN 按钮立即隐藏；拖动产生的滚动不触发重新显示，拖动结束后也不恢复
  - **AC-7**（FR-004）：GIVEN 用户不在底部 WHEN 用触摸（触摸屏滑动）滚动 THEN 按钮不显示（触摸板双指滚动产生 wheel 事件，等同滚轮，可触发）
- 场景 3：显示形态与点击行为
  - **AC-8**（FR-002）：GIVEN 按钮处于隐藏态 WHEN 达标手势触发显示（或回底 / 拖动 / 点击触发隐藏） THEN 以不超过 200ms 的淡入 / 淡出过渡切换，不瞬现瞬隐
  - **AC-9**（FR-003）：GIVEN 按钮处于显示态 WHEN 度量按钮与消息区容器的相对位置 THEN 按钮位于右下角、与右缘和底缘各保留约 12px 间距，为绝对定位悬浮层、不挤压消息内容
  - **AC-10**（FR-004）：GIVEN 按钮显示 WHEN 点击 THEN 列表回到底部、恢复自动跟随（后续流式内容继续自动滚动）、按钮隐藏（与现 US-47 验收 2 一致）
  - **AC-11**（FR-004）：GIVEN 按钮已显示 WHEN 用户向上滚动任意幅度（滚轮上滚 / 拖动上滚 / 键盘上滚 / 触摸上滑，真实用户输入附近） THEN 按钮立即淡出隐藏，且手势累计清零——随后的向下小幅滚动不显示，需新的达标手势才重新出现
  - **AC-12**（FR-003）：GIVEN 按钮显示 WHEN 其右下角区域与用户消息重叠（所有真实用户消息常驻 `user-msg-pin` 吸附样式 zIndex 10，且在消息容器内后于按钮绘制） THEN 按钮完整可见、可点击——按钮 z 序（30）高于吸附容器（10）与置顶背景延伸条（20）、低于会话加载遮罩（40）

## 功能需求

### FR-001：显示触发条件——一次向下的滚动手势累计位移超过 1/3 视口

按钮显示的充要条件：**消息区内一次向下的滚动手势**的累计滚动位移超过消息滚动容器
可视高度的 1/3，**且**当前不在底部（沿用既有 2px 判定带口径），且会话非空。
三个条件同时成立才显示；显示后持续保持，直到 FR-004 的隐藏条件出现。

- 「一次滚动手势」指连续的向下滚轮输入构成的一次滚动：相邻滚轮输入间隔不超过短暂停
  阈值即视为同一次手势（阈值量级约 150ms，具体值由 plan 定）；手势内只有向下输入产生
  的位移计入累计。累计位移以实际发生的滚动位移计（测量口径由 plan 定）。
- 逐格慢滚若输入间隔持续小于手势阈值、累计位移最终超过 1/3，同样触发——本需求约束的
  是「单次小幅滚动不触发」，不是「缓慢滚动不触发」。
- 手势进行中累计位移首次达标且当前不在底部即显示（实时反馈，不等手势结束）。

### FR-002：快速淡入淡出

显隐切换以透明度过渡完成：显示为淡入、隐藏为淡出，单次过渡时长不超过 200ms
（「快速」的上界）。隐藏态不得拦截鼠标事件（不遮挡下层消息的点击）。

### FR-003：右下角定位与悬浮层 z 序

按钮绝对定位于消息区右下角，与容器右缘、底缘各保留小间距（12px 量级，具体值由
plan 定）；悬浮层形态保持现状（圆形、不参与文档流、不挤压消息内容）。

按钮 z 序必须高于消息内容层：所有真实用户消息常驻 `user-msg-pin` 吸附样式
（`position: sticky` + zIndex 10，未吸附时同样生效），且消息容器在 wrapper 内后于
按钮绘制——同 z 序下后绘制的用户消息会盖住按钮区域，故按钮 z 序取 30，高于吸附
容器（10）与置顶背景延伸条（20），仍低于会话加载遮罩（40）。

### FR-004：触发源白名单与点击行为

- 显示的唯一触发源是消息区内向下的滚轮输入（含触摸板双指滚动产生的 wheel 事件）。
  键盘（PageDown / 空格 / 方向键 / End）、滚动条拖动、触摸屏滑动产生的滚动一律不触发显示。
- 拖动滚动条开始时，已显示的按钮立即隐藏；拖动结束不自动恢复——重新显示只能由新的
  达标滚动手势触发。
- 隐藏条件（任一）：滚回底部、点击按钮、开始拖动滚动条、会话切换的强制回底、空会话、
  用户向上滚动（任意幅度）。
- 向上滚动即隐藏：scroll 监听检测到实际向上滚动位移（scrollTop 回退，任意幅度，含
  1px）且附近存在真实用户滚动输入（与既有滚离置位的 1s 输入门同口径——滚轮 / 拖动 /
  键盘 / 触摸都会刷新输入时刻）即隐藏已显示的按钮；布局收缩等造成的 scrollTop 回退
  没有用户输入，不隐藏。向上滚动同时清零手势累计，重新显示只能由新的达标向下手势触发。
- 点击行为不变：清滚离抑制 + 强制回底 + 恢复自动跟随，按钮随之隐藏。
- 自动滚动抑制机制（`userScrolledAway`）不变：滚轮上滚、键盘滚动、拖动仍然照旧置位
  滚离抑制，只是不再作为按钮显示信号——按钮显隐与滚离抑制解耦。

## 边界与错误路径

- 流式内容增长 / 工具输出异步展开造成的瞬时离底没有滚轮输入，按 FR-004 白名单天然
  不触发，现状「流式期间不闪现」语义保持。
- 快速一滚到底的手势：手势中段达标会开始淡入，随即滚到底触发淡出——出现一次短暂
  淡入后淡出属预期，由 FR-002 的快速过渡使其不突兀。
- 内容不足一屏（容器不可滚动）时不存在滚动位移，永不显示。
- 程序化滚动（加载会话 / forceScrollKey / 渲染前预滚）不带滚轮输入，不触发显示；
  加载后强制回底落入「滚回底部」隐藏条件。
- 拖动开始时按钮隐藏后，拖动过程中手势信号被抑制（拖动不是滚轮），不存在「拖动中
  又达标复现」的路径。
- 向上滚动隐藏与布局抖动：内容收缩（折叠 thinking / 收起 diff 等）可能造成 scrollTop
  回退，但没有对应用户输入，被 1s 输入门排除，不隐藏按钮；真实用户输入后 1s 内恰逢
  内容收缩的回退会一并隐藏——按钮此时多半已因上滚输入先隐藏，无可观察差异。
- 空会话（`isEmpty`）不显示按钮，保持现状。

## 非目标

- 不做未读计数、回到某个历史位置等扩展语义——按钮仍是纯定位操作。
- 不改自动滚动抑制逻辑本身（滚离判定、强制回底入口、跟随恢复均保持现状）。
- 不重设计按钮样式（图标、配色、尺寸不变），只调定位与显隐过渡。
- 触摸屏滑动的手势识别不在本期（触摸屏用户改用拖动或键盘；如需支持另行立 spec）。
