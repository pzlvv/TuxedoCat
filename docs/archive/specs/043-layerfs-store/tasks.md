# 任务分解：LayerFS 内核库 · 对象库地基（上游对齐版）

执行顺序 = 依赖序：先接线 workspace 与双 crate 骨架（T001），再自底向上实现
`layerfs` 核心（身份 / 封装 → CDC / 策略 → Save / Reader 端口面，T002–T006）、
`layerfs-sqlite` 适配器（打开 → provider → 并发车道 → seal → 平台缝，T007–T011），
然后 AC 级集成测试（T012）、as-built 文档与 ADR（T013）、全量闸门（T014）。
对照基线：上游 v1.1.0（`9f97a7ec95b662e9cb288704afa165feff132cfa`，见 spec
「上游对齐口径」）；需求见 [spec.md](spec.md)，技术方案见 [plan.md](plan.md)。
