# 用户故事分册：工具与技能

需求基线索引（附录 e2e 映射、未覆盖豁免段）见 [user-stories.md](../user-stories.md)。
本册收录 EP-7 工具与技能与 US-50 联网搜索（客户端工具）。

## EP-7 工具与技能

### US-27 斜杠命令与技能触发

作为用户，我希望用 `/技能名` 直接触发技能（含内置命令如 `/commit`、`/spin`），以便
把常用流程固化成一键操作。

验收标准：

1. 技能来自 bundled → 项目 `<configDir>/skills/` → 用户 `~/<configDir>/skills/`。
2. 内置命令不进 LLM 上下文，执行后 UI 收到 `commandDispatched` 做客户端动作
   （如 `/spin design` 打开设计器）。
3. 技能与内置命令同名时技能被忽略并给出 WARNING。

### US-28 工具执行与结果回填

作为用户，我希望助手执行工具（Bash/Read/Write/Edit/Grep/Glob/TodoWrite/子代理…）后
把结果带回下一轮推理，直到给出最终答复，以便一次指令完成多步任务。

验收标准：

1. 工具调用 → （按权限策略确认）→ 执行 → 结果作为 tool_result 回传 LLM → 循环直至
   最终文本，整轮以 `queryEnd` 结束。
2. 工具输出按卡片实时更新（流式输出、行数、耗时）。

### US-29 MCP 服务器开关

作为用户，我希望在功能菜单里逐个启用/禁用 MCP 服务器并看到连接状态，以便控制可用
的外部工具。

验收标准：

1. 菜单 MCP 分组每服务器一行开关；状态小字显示 连接中/N 个工具/连接失败。
2. 切换后宿主收到 `setMcpEnabled`，core 落盘并广播新状态。

### US-45 命令转入后台

作为用户，我希望把正在前台执行的 Bash 命令转入后台继续运行，以便长命令不再挡住对话，
等它完成或我发新消息时再继续（`docs/features/background-bash.md`）。

验收标准：

1. Bash 卡片执行中在「复制命令」左侧显示「转后台」按钮，点击后宿主收到
   `backgroundBashTool`（会话 ID + 工具调用 ID）；卡片完成后按钮消失，重复点击无副作用。
2. 转换后结果照常作为 tool_result 回填（状态成功、带 `bg-auto-` 后台任务 ID），但本轮
   agent 循环暂停：不再发起下一次 LLM 请求，会话回到等待用户输入（终止按钮因仍有后台
   任务为黄）。
3. 队列有消息时立刻续跑：新用户消息、后台任务完成通知（或 reminder）到达即拉起新一轮，
   接续由队列消息触发；转后台结果本身不触发接续。

## 联网搜索（客户端工具）

### US-50 联网搜索与网页抓取（客户端工具）

作为用户，我希望 AI 回答时能联网搜索与抓取网页（DeepSeek Search / Fetch），且这一
能力对我配置的任何 API 协议（Completion / Anthropic / Responses）都可用，以便信息
不过时、也不被协议绑定。

验收标准：

1. 会话联网搜索开启时，模型可调用 `WebSearch`（按查询词搜索，返回逐条标题 / 链接 /
   摘要）与 `WebFetch`（抓取单个网页返回 Markdown 正文）两个工具；关闭时两个工具
   不出现在模型的工具清单里。
2. 设置页的联网搜索复选框不按默认模型的协议置灰：任何协议下都可勾选，保存后作为
   新对话默认值。
3. 两个工具调用在时间线渲染为工具卡片（搜索显示查询词、抓取显示 URL），成功 /
   失败状态与其它工具卡片一致。
4. 未配置 `api.deepseek.com` 服务商时，工具调用返回明确错误（指明需配置），会话不
   中断。
