# 用户故事分册：对话与输入

需求基线索引（附录 e2e 映射、未覆盖豁免段）见 [user-stories.md](../user-stories.md)。
本册收录 EP-1 对话核心、EP-2 输入区与会话配置、EP-13 会话交互增强。

## EP-1 对话核心

### US-1 发送消息并获得流式回复

作为用户，我在输入框输入文字并按 Enter（或点击发送按钮），希望消息立即上屏、助手回复
以流式方式逐字呈现，以便我尽早读到答案。

验收标准：

1. 输入框为空或只有空白时发送按钮不可用；有内容时可用。
2. Enter 发送、Shift+Enter 换行；输入法合成状态下的 Enter 不触发发送。
3. 发送后用户消息立即出现在消息区，助手回复按增量渲染（流式期间有思考动画兜底）。
4. 助手回复支持 Markdown（GFM、数学公式），fenced 代码块带语言高亮。
5. 流式结束后回复固定为完整 Markdown 渲染结果。
6. 输入框高度随内容行数自适应：内容在 1 到 12 行之间时高度恰好容纳全部内容、不出现
   滚动条；超过 12 行后高度停在上限并出现框内滚动条。粘贴多行文本与逐行键入得到
   相同的高度。

### US-2 中止进行中的回复

作为用户，当助手回答跑偏或我改变了主意，我希望点「终止」按钮立即停止本轮查询，以便
省下时间和 token。

验收标准：

1. 终止按钮三态：查询 / 压缩进行中为红色可点；查询停下但仍有后台任务或子代理为黄色
   可点；都为空时为灰色不可点（`docs/features/abort-button.md`）。
2. 点击后宿主收到 `abort`（携带会话 ID）。首次点击只中止前台查询，后台任务与子代理
   继续运行、按钮转为黄色；再次点击才中止它们。
3. 中止时若该会话有排队中的消息，排队内容回填到输入框供编辑重发。
4. 中止后 `*User Interrupted*` 以 once 通知显示（[webview-ui.md 第 11 节](../../hosts/webview-ui.md#11-消息区视图行为)）：
   停在时间线末位、下一条消息出现即消失；core 把它记进 `meta.json` 的 `onceMessage`
   （一个对话至多一条），重开 / 刷新会话时恢复到末位。

### US-3 消息排队

作为用户，当助手正在处理上一条消息时我又输入了新消息，希望新消息排队并在本轮结束后
自动继续，以便我不用干等。

验收标准：

1. 引擎忙碌时发送的消息以「等待中」横幅显示（含图片数量提示），并可按提示重新提交修改。
2. 本轮结束后排队消息自动作为下一轮输入提交。
3. 用户主动中止时排队消息不提交，回填输入框。

### US-4 查看思考过程与流式统计

作为用户，我希望折叠查看助手的 thinking 内容与流式性能统计（首字耗时、解码速率），
以便判断回答质量与耗时。

验收标准：

1. thinking 内容渲染为可折叠区块（默认收起），标题含 `thinking` 字样。
2. 流式期间统计按字符计（chars），结束后按 token（tok）显示。
3. 无思考内容的回复不显示该区块。

### US-5 输入历史与斜杠命令补全

作为用户，我希望输入框为空时按 ↑/↓ 翻阅我发过的历史命令、输入 `/` 时弹出技能/命令
补全，以便快速复用。

验收标准：

1. 历史按会话保存，最多 50 条；↓ 退到底后恢复未发送的草稿。
2. 输入 `/` 弹出列表，↑/↓（或 Ctrl+N/P）移动、Enter/Tab 选中、Esc 关闭。
3. 内置命令带 `cmd` 角标；选中后替换 `/命令` 前缀、保留其余文本。

### US-6 粘贴图片发送

作为用户，我希望直接在输入框 Ctrl+V 粘贴截图一起发送，并在发送前可移除，以便描述
界面问题。

验收标准：

1. 粘贴后显示缩略图，缩略图右上角 hover 出移除按钮（`移除图片`）。
2. 发送时消息携带图片；排队/回填时图片数量被保留。

### US-7 未配置服务商时的引导

作为用户，首次使用尚未配置任何模型服务时，我希望输入区直接引导我去设置页，而不是
让发送静默失败。

验收标准：

1. 未完成 provider 配置时输入框禁用，占位层提示「点击设置」打开配置面板。
2. 配置完成并保存后输入框恢复可用。

## EP-2 输入区与会话配置

### US-8 功能开关菜单

作为用户，我希望在输入区一个菜单里集中切换模型、联网搜索、MCP、提示词模式、询问
模式与思考强度，以便不动离开对话流。

验收标准：

1. 菜单项顺序：设置、Spin 设计、联网搜索、MCP、模型、提示词模式、询问模式、思考强度。
   「联网搜索」开关的是 `WebSearch` / `WebFetch` 两个客户端工具的注入（对所有
   API 协议生效）；极简提示词模式下该开关禁用。
2. 模型为三级子菜单（服务商 → 模型），当前模型有选中标记；切换后宿主收到 `setModel`。
   模型列表限高滚动，展开时当前选中的模型滚动到列表中间。
3. 模型菜单顺序由 `settings.json` 决定：服务商顺序即 `llm.providers` 的书写顺序、
   模型顺序即各 provider `models` 数组的书写顺序，网关拉取不参与菜单排序；默认模型
   不在 `models` 里时补回列表头部，保证当前选中项在菜单中可见。
4. 询问模式（总是/关键/从不）、思考强度（关/低/高/最高）、提示词模式（普通/极简/混合）
   以分段控件呈现，切换后宿主收到对应 `setAgentMode` / `setThinkingMode` / `setPromptMode`。
5. 会话配置未就绪时菜单显示加载态，不显示猜测值。
6. 二 / 三级弹层在右侧放不下时翻到父级左侧完整显示，不内联；只有左翻后仍越出
   webview 左缘时才改为在菜单面板内内联展开。内联只作用于模型分组（MCP 分组
   恒为飞出弹层）；内联态「模型」标题与其它一级菜单项左对齐。
7. 二 / 三级弹层与一级面板同形态（1px 主题边框 + 6px 圆角）；内联展开的列表不单独
   加边框，随一级面板。菜单滚动条压在面板底色之上：面板底色铺满滚动条槽位，thumb
   为不透明主题色。

### US-9 上下文用量与手动压缩

作为用户，我希望看到当前上下文 token 用量进度条，并点击它触发对话压缩，以便长对话
不让上下文爆掉。

验收标准：

1. 用量条显示 `used/total (K)`，颜色随占用率从绿到红。
2. 点击用量条宿主收到 `requestCompress`；压缩完成后进度条按新值刷新。
3. 会话忙碌时请求压缩后，用量文本显示「准备压缩」且不可再次点击；实际开始压缩或
   排队清除后还原为 `used/total (K)`。

### US-10 当前文件引用开关

作为用户在编辑器选中文件发送消息时，我希望状态条显示当前文件 chip（文件名 + 行号
区间），并可一键切换「文件信息不发给 LLM」，以便控制上下文内容。

验收标准：

1. 状态条显示文件 chip（文件名 + 行号区间）；**默认为隐藏态**（文件信息不发给
   LLM），点击 chip 切换隐藏 / 恢复。
2. 隐藏状态下发送的消息不携带文件信息；恢复态发送携带 filePath / selectedLines。

### US-11 余额与缓存命中率展示

作为用户，我希望在输入区状态条看到账户余额与缓存命中率的瞬时值，以便感知消耗。

验收标准：

1. 余额显示金额或「无限」；查询失败时清空显示。
2. 缓存命中率 tooltip 展示读取/创建/原始输入 token 明细。

### US-59 输入区任务进度按钮

作为用户，我希望输入区有一个「任务进度: 1/4」的按钮，悬停能看到当前 Todo 清单、点击能把它固定
在屏幕上，以便不往上翻消息也能知道这一轮做到哪了。

验收标准：

1. 按钮位于输入区底栏右侧按钮组最左位、紧挨菜单按钮；文案只有 `任务进度: done/total`
   （英文 `Progress: done/total`），无其它文案；当前对话没有 Todo 时不渲染按钮。
2. 计数口径为「已完成 / 总数」：`in_progress` 与 `pending` 都不计入已完成；全部完成时仍显示
   `4/4` 并保留清单。
3. 指针停留满 100ms 显示浮层（不足 100ms 移出则不出现），移出立即隐藏；点击按钮固定浮层、
   再点一次取消固定并回到悬停规则；切换对话后固定态复位。
4. 清单事实由 Core 持有：`TodoWrite` 成功后界面即时更新（不需要重新加载对话），重开应用后按
   会话文件恢复；压缩不影响已显示的进度。
5. 浮层只读：点击浮层不产生任何上行消息；配色取自 dark / light 主题，两种主题下都可读。

## EP-13 会话交互增强

### US-46 空闲发送与发送模式

作为用户，我希望在会话忙碌时把消息标记为「空闲发送」，等它真正空闲后再自动发出，
以便排队追问而不打断进行中的工作。

验收标准：

1. 发送按钮旁有下拉箭头，菜单含「立即发送」「空闲发送」两项；「立即发送」与主按钮
   等价；选择是当次动作，不记忆、不改变主按钮语义（主按钮恒为立即发送）。
2. 会话忙碌时选「空闲发送」：消息不进入本轮、不上送宿主，输入区上方出现挂起横幅并
   标明「空闲后发送」（与忙碌排队的「等待中」可区分）。
3. 该会话空闲后挂起项自动按立即发送语义发出，横幅消失；此刻会话若又忙碌则按既有
   排队语义处理，消息不丢。
4. 挂起项支持「编辑」（撤回到输入框）与「删除」（丢弃），都是即时本地动作；挂起期间
   不能再发送第二条（一次一条）。
5. 用户中止会话时挂起项回填输入框、不再自动发出；会话被关闭 / 释放或 webview 重载后
   挂起项清除 / 丢失，不再发出。

### US-47 跳到底部

作为用户，我希望在长对话里向上翻阅后能一键回到最新消息，以便继续跟进。

验收标准：

1. 消息列表位于底部时不出现在底部按钮；消息区内一次向下的滚动手势累计位移超过消息区
   可视高度 1/3 且不在底部时，右下角快速淡入「跳到底部」圆形按钮，且不被消息内容遮挡。
   键盘、滚动条拖动、触摸滚动不触发显示；拖动滚动条按下时已显示的按钮隐藏；用户向上
   滚动（任意幅度）时已显示的按钮立即隐藏。
2. 点击按钮列表滚回底部并恢复自动跟随（后续新消息继续自动滚动），按钮消失。

### US-48 标签页右键菜单

作为用户，我希望在桌面端右键工作区标签页直接执行常用操作，以便不进菜单就能整理
会话与工作区。

验收标准：

1. 右键标签页弹出原生菜单：关闭、关闭所有空闲会话、关闭其它所有工作区、打开命令行。
2. 「关闭」与点标签页 × 完全一致（有忙碌会话先二次确认）。
3. 「关闭所有空闲会话」只作用于右键的工作区，候选是该工作区已打开的对话视图（含子
   代理对话）：空闲会话关闭（当前选中的对话空闲也包含在内），忙碌（含等待用户）不动；
   其它工作区与标签页不受影响。只出现在对话列表、没有打开视图的会话不在候选内。本地
   与远程（SSH）工作区同语义。
4. 「关闭其它所有工作区」在任一其它工作区有忙碌会话时先弹一次汇总确认，确认后全部
   关闭、取消则全部不动；无忙碌直接关。
5. 「打开命令行」在该工作区根目录拉起系统终端；远程（SSH）工作区或目录已不存在时
   置灰。「关闭其它所有工作区」只有一张标签时置灰，「关闭所有空闲会话」在该工作区
   没有已打开的空闲对话时置灰。

### US-49 子代理并发上限

作为用户，我希望同一对话里派生的子代理最多 4 个同时运行、超出的自动排队等前面的
完成后再启动，以便 fan-out 任务有确定的资源上界，也不会出现卡死机器的无限并发。

验收标准：

1. 同一父会话同时运行的子代理最多 4 个：一轮内并行发起 ≤ 4 个 `Agent` 调用全部
   立即启动（工具结果形态与排队前一致）；超出上限的调用在工具调用内排队，拿到
   空闲槽位前不创建子代理会话（侧栏不出现新会话）。
2. 任一子代理结束（完成 / 被中止 / 失败）立即释放槽位，最早的排队调用按 FIFO 启动；
   同轮与后续轮次发起的调用共用同一队列，不同父会话之间互不挤占。
3. 排队中的调用属前台查询：中止父会话前台时排队调用全部取消（工具结果为取消
   文案）且不创建会话，已运行的子代理不受首次中止影响（见
   [abort-button.md](../abort-button.md) 的三态语义）。

### US-51 子代理角色 Explorer（文件浏览专用）

作为用户，我希望派生文件浏览专用的只读子代理（`Agent` 的 `agentRole="Explorer"`），
它只有 Read / Glob / Grep（外加回投必需的 Reply）工具，以便 fan-out 的「找文件 /
看代码」子任务不会误改工作区，也不受主对话的会话级配置干扰。

验收标准：

1. `Agent` 工具接受 `Master` 与 `Explorer` 两个角色（精确匹配，大小写敏感）：Explorer
   子代理的工具清单恰为 Read / Glob / Grep / Reply / TodoWrite——无其余内置工具、无
   `mcp__*`；白名单外的工具调用被拒绝（错误文案点名该角色可用的工具），命令不执行、
   会话不中止。
2. **本地**子代理的会话级配置按角色固定：非 Master 提示词预设恒 normal、联网搜索恒关、
   MCP 工具恒空；Master 子代理维持继承现状。跨工作区派发的对话**不适用角色固定**
   ——会话级配置全量继承创建者、不按角色裁剪；例外是提示词模式恒 normal、不继承
   （specs/025 FR-005）。生命周期（并发
   槽位与 FIFO 排队、中止传播、Reply 回投与 Reminder）与 Master 完全一致。
3. 打开非 Master 的**本地**子代理会话视图时，输入区选项菜单的提示词模式 / 联网搜索 /
   MCP 服务器三项置灰且点击不产生任何变更；跨工作区派发的对话联网搜索 / MCP 不置灰
   （全量继承），提示词模式置灰（恒 normal，specs/025 FR-005）。普通会话与 Master
   子代理（含 Spin 起的子代理）视图照常可操作。
4. 子代理会话的输入框禁用（「非用户创建对话无法输入」，specs/025 FR-004）——「红边框 +
   警告横幅、确认后可发送」的旧行为由统一禁用态取代。

### US-52 abort 黄灯悬停预览后台任务与子代理

作为用户，我希望 abort 按钮黄灯时悬停能预览正在运行的后台任务与子代理，以便在决定
是否整体中止前看到「收尾中还剩什么」（specs/019，
[abort-button.md](../abort-button.md)）。

验收标准：

1. 黄色态悬停满 1 秒显示只读浮层，列出运行中的后台任务（描述，与命令不同时附命令）
   与运行中的子代理（创建时描述，递归含下层）；红色 / 灰色态与恢复态 spin 悬停无浮层。
2. 移出按钮浮层立即消失；显示期间明细随快照刷新，全部结束时浮层随之关闭。
3. 浮层只读，点击无副作用、不产生任何上行；abort 点击的中止范围不变（整体判定）。
