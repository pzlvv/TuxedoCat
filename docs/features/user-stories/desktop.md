# 用户故事分册：桌面端

需求基线索引（附录 e2e 映射、未覆盖豁免段）见 [user-stories.md](../user-stories.md)。
本册收录 EP-8 桌面端窗口与标题栏、EP-9 多工作区、EP-10 预览与 Spin、EP-12 侧栏文件
浏览器（均为桌面端）。

## EP-8 桌面端窗口与标题栏（桌面端）

### US-30 完整模式与悬浮窗切换

作为用户，我希望在完整模式（侧栏 + 聊天）与窄悬浮窗之间一键切换，悬浮窗可置顶，
以便把助手钉在角落。

验收标准：

1. 标题栏模式按钮切换；未打开工作区时禁用切换。
2. 悬浮窗隐藏原生侧栏，对话列表改由 webview 顶栏渲染（运行期切换渲染方）。
3. 悬浮窗专属「总在最前」开关；窗口模式与置顶状态持久化，重启恢复。

### US-31 窗口控制与状态恢复

作为用户，我希望标题栏提供最小化/最大化/关闭、双击最大化，窗口位置尺寸记忆上次
状态，以便符合桌面使用习惯。

验收标准：

1. 最小化/最大化(还原)/关闭可用；悬浮窗下最小化进托盘。
2. 位置与尺寸按模式分别持久化并在下次启动恢复。

### US-32 主题切换

作为用户，我希望主题在 跟随系统/浅色/深色 间切换并立即生效，以便适配环境光。

验收标准：

1. 偏好设置窗口里主题单选切换，全部视图（标题栏/侧栏/聊天/预览）即时应用。
2. 跟随系统时系统主题变化即时传播。

### US-33 系统托盘与任务提醒

作为用户，最小化到托盘后希望后台任务完成时图标闪烁提醒，以便不错过结果。

验收标准：

1. 托盘图标状态点：绿=全部空闲、红=运行中、黄=等待用户确认。
2. 任一后台任务结束（完成或转等待用户确认）且窗口不在前台时图标闪烁，颜色跟随整体状态
   （多个任务在跑时其中一个完成也提醒，此时仍为红点；全部完成绿点、有任务等用户黄点）；
   任意窗口聚焦后停止。完成的定义是任务真的结束：完成时刻队列里还有活（空闲挂起项
   紧随提交、排队压缩续跑等，表现为短暂 idle 后又回到运行）不算完成、不提醒，
   由续跑任务自己的完成再提醒。
3. 右键菜单「显示 / 退出」；左键唤出主窗口。
4. 闪烁提醒的同时播放一次提示音（Electron 宿主；VS Code 宿主不播放）；提示音默认关闭、
   默认音量 50%，可在偏好设置窗口里开启并调整音量（调整后预览播放一次）。

### US-34 全局唤醒快捷键

作为用户，我希望全局快捷键（默认 Ctrl+Alt+X）随时唤出或隐藏窗口并自动聚焦输入框，
并在设置对话框里改键，以便秒回对话。

验收标准：

1. 窗口不在前台按快捷键唤出并聚焦输入框；在前台再按隐藏回托盘。
2. 偏好设置窗口里点击快捷键字段后录制新组合（Esc 取消录制），录到合法组合即生效并持久化。

### US-44 侧栏宽度拖拽

作为用户，我希望拖动侧栏右缘改变侧栏宽度，以便给对话列表或聊天区分配更多空间。

验收标准：

1. 侧栏右缘有拖拽手柄（悬停高亮、col-resize 光标），按住水平拖动即时生效：
   侧栏与聊天区的分界跟随指针，拖出侧栏边界不丢事件。手柄占据侧栏最右侧一条竖带，
   对话列表 / 文件树的滚动条在该竖带左侧结束——两条带互不重叠，滚动条可正常拖动，
   浅色主题下滚动条也不与侧栏右边框相接。
2. 宽度有上下限（约 200~640，随实现细节可调），且永远不会把聊天区挤到不可用；
   窗口缩到很窄时侧栏自动让位，窗口拉宽后恢复到用户拖过的宽度。
3. 宽度持久化（宿主本地状态），重启后按上次的宽度恢复；双击手柄恢复默认宽度。
4. 浮窗模式侧栏整体隐藏，不受该宽度影响；切回完整模式原样恢复。

## EP-9 多工作区（桌面端）

### US-35 打开与切换本地工作区

作为用户，我希望同时打开多个本地目录作为工作区，以标签页切换，每个工作区有独立的
对话与配置上下文。

验收标准：

1. 四个入口可打开本地目录（菜单 Ctrl+O、标签页 +、侧栏空态、聊天空态）。
2. 标签页显示目录名（远程为 `目录名@主机名`，如 `TEST@192.168.1.1`）、活动项高亮、可关闭、可拖拽排序。
3. 切换工作区时聊天区切到该目录最近对话；关闭工作区销毁其对话视图并中止查询，磁盘
   数据保留。
4. 上次打开集合与活动项持久化，重启恢复；目录缺失的项保留并标红。
5. 标签页流水灯按工作目录归并该目录全部会话的运行时状态：任一会话等待用户确认
   显示黄点（优先级最高），否则任一会话运行中显示蓝点，全部空闲不点亮。
6. 鼠标中键点击标签页走与关闭按钮相同的关闭入口（并抑制中键自动滚动）。
7. 关闭的工作区下仍有对话非 idle 时，先弹确认框（自绘消息框，默认与取消都落在「取消」）；
   确认后才中止这些对话并关闭。

### US-36 打开远程工作区

作为用户，我希望填 SSH 表单连接远端 Core，并在远端目录选择器里选定目录作为远程工作区，
以便操作远程机器。

验收标准：

1. SSH 两步流：连接成功后立即弹出远端目录选择器（路径可编辑、前缀补全、
   新建/重命名/删除，删除有两阶段确认）。
2. 建链中标签页显示呼吸点；失败显示红点与聊天区占位页（带重新连接按钮）。失败落定
   （建链失败信号与可达性探测二者的到达顺序不定）后标签页自动转红点，无需用户交互。
3. 远程工作区与本地工作区在标签页/侧栏/对话上同构。
4. SSH 连接成功后整表单（host / 端口 / 用户 / 口令，口令明文）记入宿主本地连接历史：
   最近在前、去重键 `user@host:port`（同机重连只顶到最前并更新口令）、最多 20 条。
   host 输入框聚焦弹出最多 6 条候选：前缀匹配排在非前缀匹配之前、同级按最近连接，
   端口 22 不显示、非 22 追加 `:port`；选定候选回填整表单并收起候选；候选行的删除
   按钮清掉这条历史并同步落盘。窗口打开不自动聚焦输入框，无历史时不弹候选。

### US-37 最近工作区

作为用户，我希望从「最近的工作区」快速重开常用目录，以便少点几次鼠标。

验收标准：

1. 最近列表上限 20；本地项过滤已不存在的目录；点击即打开或激活。

### US-53 标签页快捷键切换与改键

作为用户，我希望用快捷键（默认 Ctrl+Tab / Ctrl+Shift+Tab）在标签页之间切换工作区，
并可在偏好设置里改键，以便不动鼠标顺序浏览工作目录。

验收标准：

1. 「下一标签 / 上一标签」按标签页顺序把活动项移向相邻项并环绕（末项回首项、
   首项到末项）；打开集合不足 2 项时不动作；完整模式下主窗口内焦点在侧栏 / 标题栏 /
   聊天区任意一处均生效；浮窗模式不动作。
2. 组合键在偏好设置窗口快捷键区逐行录制改键（Esc 取消、原值保持）；录制组合与
   另一条标签快捷键、菜单既有组合（Ctrl+O、Ctrl+Shift+O、Ctrl+Shift+I）或唤醒
   快捷键冲突时拒绝保存，行内显示冲突原因。
3. 改键持久化（宿主本地状态），重启后仍按新组合生效、旧组合失效；菜单条目展示
   与生效组合一致，点击条目执行同一动作。

### US-56 跨工作区代理

作为用户，我希望在一个工作区的对话里把子任务派给另一个已打开的工作区（本机或 SSH
远程），子代理在那边以自己的身份和角色运行，两边都能跳转与中止，以便把「改这个仓库」
这类事项交给对应工作区的代理而不是在当前目录硬做。

验收标准：

1. 每个已打开工作区有代理身份 `<机器名>:<工作区路径>`（本地取机器名、远程取 SSH 目标
   主机）；`Agent` 的 `target` 传该身份时，子代理对话创建在目标工作区，`role` / `title` /
   `parentSessionId` / `project` 按目标工作区落盘；不传 `target` 或等于当前工作区时按
   原策略建本机子代理。
2. 目标工作区的对话列表里，子代理挂在占位父对话下；占位节点不是真实会话（无消息、
   无运行时、无重命名 / 删除入口），打开只显示跳转页。
3. `Agent` 工具卡片与占位页都能跨工作区跳转（切标签页 + 开对话）；目标工作区未打开时
   链接不可用，不自动打开。
4. 发起方 abort 能中止目标工作区的子代理（`subAgentRunning` 覆盖远程子代理）；
   目标工作区一侧也可独立中止；目标不可达时按结束收敛。
5. 目标工作区 Core 不可达 / 身份未打开 / 身份歧义 / `target` 空串：工具错误，不创建
   对话、不占用并发槽位。

### US-57 `@` 工作区补全与提醒注入

作为用户，我希望在输入框输入 `@` 就能从已打开的工作区里选一个（排除当前工作区），
发送后模型知道应该用 `Agent.target` 把事项代理过去，以便不用记身份字符串。

验收标准：

1. 首字符 `@` 弹出候选菜单（打开集合顺序，排除当前会话所属工作区）；查询词按身份 ID
   与目录名过滤，ID 命中优先；无候选时不显示菜单。
2. 选中插入 `@<身份> `，身份含空白时插入 `@"<身份>" `；保留光标之后原文、光标置于末尾；
   键盘操作与 `/` 补全一致；只认首字符；身份之后可多行。
3. 宿主声明支持跨工作区代理时，以 `@<身份>` 开头的消息在用户消息之后注入一条 silent
   reminder（点名 `target` 与 `Agent` 工具）；宿主不支持时按普通文本处理。
4. 身份不存在时 reminder 照常注入，错误在 `Agent` 执行时暴露。

## EP-10 预览与 Spin（桌面端）

### US-38 文件与虚拟文档预览

作为用户，点击消息里的文件链接希望打开预览（Monaco 视图/只读内容模式，定位到选中
行），图片则用图片预览窗，以便不改上下文快速查看。

验收标准：

1. 文件链接打开 Monaco 窗口并定位行号；`showVirtualDocument` 以只读模式展示内容。
2. 图片走内置图片预览窗口。
3. Monaco 与图片查看器窗口的标题为打开文件名（basename）；Markdown 预览标题为传入标题。
4. 三类查看器（Monaco / 图片 / Markdown）共用一个窗口名额：新开请求顶替现存查看器窗口
   （继承其位置尺寸），桌面同时至多一个查看器窗口；Spin 设计器与 Mermaid 预览不占名额。
5. 查看器窗口与 Spin 设计器窗口各自记忆上次位置与尺寸（多屏拔插后矩形失效回退默认尺寸）。
6. 本地与远程查看器在源文件被外部修改后自动刷新：本地由宿主文件系统事件驱动，远程由远端 Core 监听并主动推送（不轮询）；刷新保持图片缩放 / 平移、Markdown 滚动与 Monaco 滚动 / 光标位置。虚拟文档与 diff 不监听。

### US-39 Spin 设计器

作为用户，我希望可视化编辑 `spin.json` 工作流并执行 `/spin` 流程，以便编排多步子代理
任务。

验收标准：

1. 输入区菜单「Spin 设计」或 `/spin design` 打开设计器窗口；已开则聚焦复用。
2. 保存写回会话所属 Core 所在机器的会话目录（远程工作区即远端；Core 内串行写盘）与导出
   JSON；执行完成后窗口数据自动刷新。
3. spin 模式**单向**：`/spin` 进入后主输入框永久禁用（placeholder 提示「Spin 模式下不响应
   用户输入」），完成 / 中止 / 失败都不退出；停止按钮为黄色（spin 没有 query engine），
   点击只中止运行中的子代理并结束当前 SpinLoop。会话 `meta.json` 落盘 `workMode` 标记，
   加载时恢复禁用态；应用中断后恢复出的 spin 会话同样不退出。
4. `/spin` 执行期间父对话不参与 LLM 循环，完全由 SpinLoop 程序驱动：用户消息在 Core 侧
   也被丢弃，不入队、不触发 LLM。子代理的 Reply 只用于节点结果更新与验收判定；同一子
   代理的 Reply 只响应一次，重复或 Spin 结束后迟到的 Reply 一律忽略，不得触发父对话的
   LLM 轮次。

## EP-12 侧栏文件浏览器（桌面端）

### US-42 侧栏文件浏览器

作为用户，我希望在桌面端侧栏底部展开一个文件浏览器，浏览当前活动工作目录的文件树，
以便不离开对话也能随时查看工作区里有什么。

验收标准：

1. 侧栏底部有「文件资源管理器」分区条：默认折叠（只有一条分区条），点击展开后占侧栏 50% 高度、
   对话列表相应收窄；再点折叠回分区条。展开 / 折叠状态按工作区分别记忆（落盘，
   重载后按工作区恢复）。展开 / 折叠过渡与内容淡入只在点击分区条时播放；因切换活动
   工作区导致的状态变化直接生效，不播放过渡。
2. 文件树展示当前活动工作目录：目录排在文件之前、同类按名称排序；目录逐层懒加载
   （点开目录才读该层），单击目录即展开 / 折叠（点展开箭头只切换展开、不改选中）；
   目录展开状态与树内容在刷新后保留。
3. 分区条带刷新按钮。**每个工作区有独立的文件浏览器状态**：树缓存、目录展开、选中
   与折叠状态都按工作区保存，切换工作区标签页互不影响——切回时原样保留，不重新
   读取也不丢状态；工作区被关闭后其状态丢弃，重新打开按新工作区处理。刷新后树重新
   铺满时回到刷新前的滚动位置（内容高度不足时贴底）；刷新在途期间用户主动滚动则以
   用户位置为准。
4. 打开集合为空时不显示该分区。远程（SSH）工作区同样支持文件浏览：读取与删除走
   SSH 的 SFTP，路径为远端机器上的绝对路径；「在文件资源管理器中打开」仅本地
   工作区提供（远程项不出现在菜单里）。
5. 图标用开源图标库（lucide）按类型区分（目录 / 代码 / JSON / 文本 / 图片 / 压缩包 /
   其他），不使用 emoji；深浅色主题下均正常着色。
6. 双击文件行打开（目录不响应双击，单击已展开 / 折叠）：Markdown 文件（`.md` /
   `.markdown`）用内置 Markdown 预览窗口打开（渲染后的只读视图，非源码文本，
   内容净化——原生 HTML 不执行、危险协议链接不可点）；文本文件（代码 / 配置 / 文本
   扩展名，以及嗅探不出二进制的未知类型）用内置编辑器打开——与工具卡片点「Edit」
   预览同一窗口、同样的语法高亮效果；图片用内置图片查看器打开——滚轮以光标为锚
   缩放，放大后可拖动平移，双击在 100% 与适配窗口间切换；其它二进制文件调用系统
   默认应用打开。远程（SSH）工作区同样支持：Markdown / 文本 / 图片经 SFTP 读出进
   内置窗口；二进制文件不支持打开（已知二进制双击无响应，未知扩展名由主进程嗅探后
   拒绝），系统默认应用打开仅本地工作区提供。本地与远程打开的三类查看器（Markdown / 图片 / 文本）都会随源文件更新自动刷新：本地由文件系统事件驱动，远程由远端 Core 监听并主动推送，刷新保持当前缩放 / 滚动 / 光标位置。

### US-43 文件多选与右键菜单

作为用户，我希望对文件浏览器里的项多选后复制路径或删除，以便批量整理文件。

验收标准：

1. 点击选中单项；Ctrl+点击切换该项选中（多选）；Shift+点击选中上一次点击项到当前项
   之间的连续范围；Ctrl+A 全选可见项；Esc 或点击空白处清空选择。
2. 右键项弹出菜单：复制完整路径、复制相对路径、在文件资源管理器中打开、删除。
   右键未选中的项时先把它置为唯一选中项。
3. 复制作用于全部选中项（多行换行拼接）；「在文件资源管理器中打开」只作用于右键的
   那一项；删除作用于全部选中项。
4. 删除先弹确认框（自绘消息框，默认与取消都落在「取消」，确认框与菜单里的删除项均不使用
   危险色强调）：本地确认后移入系统回收站并刷新文件树；远程（SSH）为永久删除
   （目录连同内容、无法撤销），确认框文案标明。按 Delete 键等同菜单里的「删除」。
5. 复制与删除的路径都相对当前活动工作目录解析；相对路径复制为该目录下的相对写法。

## EP-14 远程终端（桌面端）

### US-54 远程终端窗口

作为用户，我希望为打开的远程工作区打开一个交互式终端窗口，直接在远端执行命令，
以便配合对话处理远程工作区的任务。

验收标准：

1. 标签页右键「打开终端」仅当该工作区为远程且带凭证时可用（无凭证置灰；本地工作区
   同位置为「打开命令行」）；打开的是独立窗口，标题含 `ssh://user@host` 与工作区路径，
   首标签自动连上远端 shell。
2. 同一工作区重复触发入口聚焦既有窗口不叠开；不同工作区（含同一主机的不同目录）可各开
   一个；终端属于工作区不属于会话——切换标签页、关闭会话视图都不影响终端。
3. 连接复用该 endpoint 的既有 SSH 连接（侧栏文件浏览已连着时不重复口令鉴权与主机密钥
   确认）；主机密钥变更走与远程接入同一套的新旧指纹比对告警，确认后重试、拒绝则停留
   失败态。
4. 关闭工作区时其终端窗口一并关闭（同 endpoint 其它工作区的终端不受影响）；应用退出时
   全部关闭，远端 shell 随连接由 sshd 回收。

### US-55 终端标签与交互

作为用户，我希望在终端窗口里开多个标签、复制粘贴，并在断开后手动重连，以便并行处理
多件事、丢连后不抓瞎。

验收标准：

1. 「+」新建标签并切到新页（起始目录为工作区路径），每标签一条独立 shell；✕ 关闭标签，
   shell 退出（exit）自动关标签，最后一个标签关闭时窗口关闭。
2. 键入回显、全屏程序（vim 一类）可用；窗口尺寸变化同步远端 PTY；滚动回看不少于 1000 行。
3. 复制（Ctrl+Shift+C / macOS Cmd+C，有选区）与粘贴（Ctrl+Shift+V / Cmd+V）可用。
4. SSH 断开时标签转断开态并显示原因，「重新连接」以当下尺寸重建该标签的 shell；
   不自动重连、不批量复活其它标签。
5. 主题即时跟随应用主题（深浅两套 ANSI 配色）；界面语言与字号档位在开窗时取值，
   运行期变更不热切到已开的终端窗口。
