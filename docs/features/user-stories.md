## EP-1 对话核心

### US-1 发送消息并获得流式回复

作为用户，我在输入框输入文字并按 Enter（或点击发送按钮），希望消息立即上屏、助手回复
以流式方式逐字呈现，以便我尽早读到答案。

验收标准：

1. 输入框为空或只有空白时发送按钮不可用；有内容时可用。
2. Enter 发送、Shift+Enter 换行；输入法合成状态下的 Enter 不触发发送。
3. 发送后用户消息立即出现在消息区，助手回复按增量渲染（流式期间有思考动画兜底）。
4. 助手回复支持 Markdown（GFM、数学公式），fenced 代码块带语言高亮。
5. 流式结束后回复固定为完整 Markdown 渲染结果。
6. 输入框高度随内容行数自适应：内容在 1 到 12 行之间时高度恰好容纳全部内容、不出现
   滚动条；超过 12 行后高度停在上限并出现框内滚动条。粘贴多行文本与逐行键入得到
   相同的高度。

### US-2 中止进行中的回复

作为用户，当助手回答跑偏或我改变了主意，我希望点「终止」按钮立即停止本轮查询，以便
省下时间和 token。

验收标准：

1. 终止按钮三态：查询 / 压缩进行中为红色可点；查询停下但仍有后台任务或子代理为黄色
   可点；都为空时为灰色不可点（`docs/features/abort-button.md`）。
2. 点击后宿主收到 `abort`（携带会话 ID）。首次点击只中止前台查询，后台任务与子代理
   继续运行、按钮转为黄色；再次点击才中止它们。
3. 中止时若该会话有排队中的消息，排队内容回填到输入框供编辑重发。

### US-3 消息排队

作为用户，当助手正在处理上一条消息时我又输入了新消息，希望新消息排队并在本轮结束后
自动继续，以便我不用干等。

验收标准：

1. 引擎忙碌时发送的消息以「等待中」横幅显示（含图片数量提示），并可按提示重新提交修改。
2. 本轮结束后排队消息自动作为下一轮输入提交。
3. 用户主动中止时排队消息不提交，回填输入框。

### US-4 查看思考过程与流式统计

作为用户，我希望折叠查看助手的 thinking 内容与流式性能统计（首字耗时、解码速率），
以便判断回答质量与耗时。

验收标准：

1. thinking 内容渲染为可折叠区块（默认收起），标题含 `thinking` 字样。
2. 流式期间统计按字符计（chars），结束后按 token（tok）显示。
3. 无思考内容的回复不显示该区块。

### US-5 输入历史与斜杠命令补全

作为用户，我希望输入框为空时按 ↑/↓ 翻阅我发过的历史命令、输入 `/` 时弹出技能/命令
补全，以便快速复用。

验收标准：

1. 历史按会话保存，最多 50 条；↓ 退到底后恢复未发送的草稿。
2. 输入 `/` 弹出列表，↑/↓（或 Ctrl+N/P）移动、Enter/Tab 选中、Esc 关闭。
3. 内置命令带 `cmd` 角标；选中后替换 `/命令` 前缀、保留其余文本。

### US-6 粘贴图片发送

作为用户，我希望直接在输入框 Ctrl+V 粘贴截图一起发送，并在发送前可移除，以便描述
界面问题。

验收标准：

1. 粘贴后显示缩略图，缩略图右上角 hover 出移除按钮（`移除图片`）。
2. 发送时消息携带图片；排队/回填时图片数量被保留。

### US-7 未配置服务商时的引导

作为用户，首次使用尚未配置任何模型服务时，我希望输入区直接引导我去设置页，而不是
让发送静默失败。

验收标准：

1. 未完成 provider 配置时输入框禁用，占位层提示「点击设置」打开配置面板。
2. 配置完成并保存后输入框恢复可用。

## EP-2 输入区与会话配置

### US-8 功能开关菜单

作为用户，我希望在输入区一个菜单里集中切换模型、联网搜索、MCP、提示词模式、询问
模式与思考强度，以便不动离开对话流。

验收标准：

1. 菜单项顺序：设置、Spin 设计、联网搜索、MCP、模型、提示词模式、询问模式、思考强度。
2. 模型为三级子菜单（服务商 → 模型），当前模型有选中标记；切换后宿主收到 `setModel`。
   模型列表限高滚动，展开时当前选中的模型滚动到列表中间。
3. 模型菜单顺序由 `settings.json` 决定：服务商顺序即 `llm.providers` 的书写顺序、
   模型顺序即各 provider `models` 数组的书写顺序，网关拉取不参与菜单排序；默认模型
   不在 `models` 里时补回列表头部，保证当前选中项在菜单中可见。
4. 询问模式（总是/关键/从不）、思考强度（关/低/高/最高）、提示词模式（普通/极简/混合）
   以分段控件呈现，切换后宿主收到对应 `setAgentMode` / `setThinkingMode` / `setPromptMode`。
5. 会话配置未就绪时菜单显示加载态，不显示猜测值。
6. 二 / 三级弹层在右侧放不下时翻到父级左侧完整显示，不内联；只有左翻后仍越出
   webview 左缘时才改为在菜单面板内内联展开。内联只作用于模型分组（MCP 分组
   恒为飞出弹层）；内联态「模型」标题与其它一级菜单项左对齐。

### US-9 上下文用量与手动压缩

作为用户，我希望看到当前上下文 token 用量进度条，并点击它触发对话压缩，以便长对话
不让上下文爆掉。

验收标准：

1. 用量条显示 `used/total (K)`，颜色随占用率从绿到红。
2. 点击用量条宿主收到 `requestCompress`；压缩完成后进度条按新值刷新。

### US-10 当前文件引用开关

作为用户在编辑器选中文件发送消息时，我希望状态条显示当前文件 chip（文件名 + 行号
区间），并可一键切换「文件信息不发给 LLM」，以便控制上下文内容。

验收标准：

1. 状态条显示文件 chip（文件名 + 行号区间）；**默认为隐藏态**（文件信息不发给
   LLM），点击 chip 切换隐藏 / 恢复。
2. 隐藏状态下发送的消息不携带文件信息；恢复态发送携带 filePath / selectedLines。

### US-11 余额与缓存命中率展示

作为用户，我希望在输入区状态条看到账户余额与缓存命中率的瞬时值，以便感知消耗。

验收标准：

1. 余额显示金额或「无限」；查询失败时清空显示。
2. 缓存命中率 tooltip 展示读取/创建/原始输入 token 明细。

## EP-3 消息呈现

### US-12 代码块复制

作为用户，我希望一键复制助手回复里的代码块并得到「已复制」反馈，以便粘到编辑器里。

验收标准：

1. hover 代码块右上角出现「复制」按钮；点击后写入剪贴板并变为「已复制」约 2 秒。

### US-13 Mermaid 图表预览

作为用户，助手回复里的 mermaid 代码块我希望就地转成图表预览，以便直读流程图。

验收标准：

1. `language-mermaid` 代码块带「预览」按钮，点击后宿主收到 `openMermaidPreview`。

### US-14 工具调用卡片

作为用户，我希望每一步工具调用（Bash/读/写/编辑/搜索/子代理…）以卡片形式展示关键
参数与输出，以便审查助手做了什么。

验收标准：

1. 卡片显示工具图标、名称与参数摘要；Bash 卡片命令可复制、可查看完整命令与输出。
   Bash 输出框与流式期间同高（缩略 / 展开卡片总高度不变）：执行完成后缩略显示
   **末尾**实测放得下的整行（overflow hidden 不出现滚动条，可见窗口钉在底部，
   与 Edit/Write 预览同一套折叠实现）；提示条位于输出框上方（chevron 朝上），整条
   铺满命令卡片、只自绘下边那一条作为与输出框之间的分割线（上 / 左 / 右三边正好落在
   卡片已有的线条上，不自绘外框）；点击展开后提示条不再占位，其高度整体转给输出框
   （卡片总高度不变），输出框出现框内滚动条，初始视点仍在底部、可向上滚动查看更早
   输出；流式期间保持滚动跟随最新输出。输出被持久化到磁盘时，「完整输出」入口与复制
   按钮并排放在命令行右侧。
2. Edit/Write 卡片内嵌 diff/内容预览（红删绿增、单词级高亮），可展开/收起；超大输出
   持久化后显示「完整输出」按钮。
3. Read 卡片路径可点击打开文件；子代理卡片可点击跳转到子会话。

### US-15 回滚编辑

作为用户，我希望对某次 Edit/Write 直接「回滚修改到此」，并在确认框里选择回滚到修改
前还是修改后，以便撤销助手的文件改动。

验收标准：

1. 卡片上的回滚按钮弹出居中确认框，二选一（修改前/修改后）+ 取消。
2. 确认后宿主收到 `rollbackEdit`（含 toolUseId、文件路径、方向）。

### US-16 长消息折叠与用户消息置顶

作为用户浏览长对话时，我希望超长消息默认折叠、真正的用户消息滚出视口时吸附置顶，
以便快速定位上下文。

验收标准：

1. 超长用户消息显示「显示完整内容/收起」切换；窗口 / 侧边栏宽度变化改变折行数时，
   切换入口随之更新（拉宽后能完整放下即隐藏，收窄后溢出即出现）。
2. 用户消息滚动到顶时吸附为整宽条（`data-pinned`），点击空白处跳回原位。

### US-17 压缩历史展开

作为用户，对话被压缩后我希望展开压缩前的历史，以便回看被摘要替代的原文。

验收标准：

1. 存在压缩归档时消息区顶部出现「展开压缩的对话历史」按钮。
2. 点击后宿主收到 `expandCompact`，返回后整批消息替换显示，压缩摘要带虚线框标识。

## EP-4 权限与用户确认

### US-18 工具执行前的权限确认

作为用户，我希望危险或写操作在执行前弹确认让我放行或拒绝，以便掌控助手对工作区的
改动。

验收标准：

1. 权限请求以 `UserChoiceOverlay` 替换主输入框原位渲染：消息文本 + 选项按钮 + 文本
   输入框。
2. 点击选项或按数字键 1-9 直接选择；也可输入自定义文本后点发送按钮提交，或在输入框内
   回车提交（Shift+回车换行）。焦点落在选项按钮上时空格 / 回车不触发确认（按钮的原生键盘
   激活被禁用），避免误触。
3. 提交后宿主收到 `respondUserChoice`（choiceId + index/reply），输入框恢复原草稿。
4. 「询问模式 = 总是」时所有工具都确认；「从不」时不打断（模型自行决策）。

## EP-5 会话管理

### US-19 对话历史与切换

作为用户，我希望打开对话历史列表、按最近排序看到全部会话（含子会话树），点击即切换，
以便延续之前的工作。

验收标准：

1. 「对话历史」按钮打开下拉面板；空态显示「暂无对话历史」。
2. 列表项显示标题、相对时间、消息数；子会话带 `sub` 角标并可折叠展开。
3. 运行中的会话有流水灯（运行蓝/等待黄）；点击条目宿主收到 `loadConversation`/
   `openConversation`（按宿主视图模式）。
4. 切换会话时显示「正在加载对话...」遮罩，加载完成后展示历史消息。
5. （桌面端）侧栏对话列表头部为「搜索框 + 新对话」：搜索框按标题过滤当前活动工作
   目录的对话，计数显示「N / M 个对话」。
6. （桌面端）切换工作目录后超过 100ms 仍未取到列表才显示「加载中」，快速命中不闪
   转圈；取到列表前不显示「暂无对话」。
7. （桌面端）侧栏「关闭」与聊天视图顶栏关闭按钮走同一关闭入口：对话非 idle（查询 /
   压缩 / 后台任务 / 子代理 / 等待用户确认任一）时先弹确认框（自绘消息框），默认与取消都落在
   「取消」；确认后才中止运行并关闭，取消则不动。从未发消息的新建会话视为空闲、
   不问。
8. 从磁盘加载会话时按 `meta.json` 记录的模型身份（provider + model）恢复会话模型：
   身份仍有效即沿用；模型不在该 provider 的模型列表 / provider 已移除则回退默认模型
   （该 provider 的默认模型；provider 已移除时为 active provider 的默认模型）并把
   回退结果写回 `meta.json`；未记录身份时取 active provider 的默认模型、不回写。
9. 子会话树按「默认展开」规则呈现：当前选中对话的祖先链默认展开（保证选中项可见）；
   选中对话自身的直接子会话数达到 5 时不默认展开（批量委派的对话不把列表撑满，用户
   仍可手动展开）。默认展开只在用户尚未显式设置过该对话的展开状态时生效；用户显式
   设置后，列表数据刷新不再改写它。该阈值是单一来源，webview 对话树与 Electron 侧栏
   共用。

### US-20 新建对话

作为用户，我希望一键新建对话并保留输入框里未发送的草稿，以便随手开新话题不丢内容。

验收标准：

1. 顶栏「新对话」按钮（桌面端为侧栏「+ 新对话」）触发新会话，未发送草稿被暂存。
2. 新会话的会话配置（模型/模式等）重置为 settings 默认值。

### US-21 重命名与智能命名

作为用户，我希望手动重命名对话，或让助手根据对话内容生成标题，以便历史列表可读。

验收标准：

1. 会话条目 hover 出「重命名」，行内输入 Enter 提交、Esc 取消；宿主收到
   `renameConversation`。
2. 「智能命名」发起后条目显示命名中状态，完成后标题刷新（`smartNamingResult`）。

### US-22 删除对话

作为用户，我希望删除不需要的对话（含其子会话），并有二次确认防误删。

验收标准：

1. 删除按钮弹出确认框「确定要删除 "..." 吗？」，确认后宿主收到 `deleteConversation`。
2. 删除当前打开的会话后视图切换到新对话（或按宿主模式关闭视图）。

## EP-6 LLM 配置

### US-23 管理服务商与模型

作为用户，我希望在设置页管理多个 OpenAI 兼容/Anthropic/Responses 服务商与各自模型
列表，以便在不同模型间切换。

验收标准：

1. 设置页以覆盖层打开（保留对话与草稿）；Provider 标签页支持新增、删除、双击设为
   当前使用。
2. 每个服务商配置 API 地址、API Key、模型列表；API Key 默认掩码，可切换明文显示
   （仅展示开关，不改保存内容）；模型行可设默认、删除、选择 API 协议
   （Responses/Completion/Anthropic）。
3. 「自动获取」从服务商拉取模型列表；未探测协议的模型弹自动检测确认（用户可跳过）。
4. 保存前校验：地址非空、不重复、至少一个服务商且各有模型；保存后宿主收到
   `saveLLMConfig`，成功后面板关闭。

### US-24 默认设置、界面语言与界面字号

## EP-13 会话交互增强

### US-46 空闲发送与发送模式

作为用户，我希望在会话忙碌时把消息标记为「空闲发送」，等它真正空闲后再自动发出，
以便排队追问而不打断进行中的工作。

验收标准：

1. 发送按钮旁有下拉箭头，菜单含「立即发送」「空闲发送」两项；「立即发送」与主按钮
   等价；选择是当次动作，不记忆、不改变主按钮语义（主按钮恒为立即发送）。
2. 会话忙碌时选「空闲发送」：消息不进入本轮、不上送宿主，输入区上方出现挂起横幅并
   标明「空闲后发送」（与忙碌排队的「等待中」可区分）。
3. 该会话空闲后挂起项自动按立即发送语义发出，横幅消失；此刻会话若又忙碌则按既有
   排队语义处理，消息不丢。
4. 挂起项支持「编辑」（撤回到输入框）与「删除」（丢弃），都是即时本地动作；挂起期间
   不能再发送第二条（一次一条）。
5. 用户中止会话时挂起项回填输入框、不再自动发出；会话被关闭 / 释放或 webview 重载后
   挂起项清除 / 丢失，不再发出。

### US-47 跳到底部

作为用户，我希望在长对话里向上翻阅后能一键回到最新消息，以便继续跟进。

验收标准：

1. 消息列表位于底部时不出现在底部按钮；消息区内一次向下的滚动手势累计位移超过消息区
   可视高度 1/3 且不在底部时，右下角快速淡入「跳到底部」圆形按钮，且不被消息内容遮挡。
   键盘、滚动条拖动、触摸滚动不触发显示；拖动滚动条按下时已显示的按钮隐藏；用户向上
   滚动（任意幅度）时已显示的按钮立即隐藏。
2. 点击按钮列表滚回底部并恢复自动跟随（后续新消息继续自动滚动），按钮消失。

### US-48 标签页右键菜单

作为用户，我希望在桌面端右键工作区标签页直接执行常用操作，以便不进菜单就能整理
会话与工作区。

验收标准：

1. 右键标签页弹出原生菜单：关闭、关闭所有空闲会话、关闭其它所有工作区、打开命令行。
2. 「关闭」与点标签页 × 完全一致（有忙碌会话先二次确认）。
3. 「关闭所有空闲会话」只作用于右键的工作区，候选是该工作区已打开的对话视图（含子
   代理对话）：空闲会话关闭（当前选中的对话空闲也包含在内），忙碌（含等待用户）不动；
   其它工作区与标签页不受影响。只出现在对话列表、没有打开视图的会话不在候选内。本地
   与远程（SSH）工作区同语义。
4. 「关闭其它所有工作区」在任一其它工作区有忙碌会话时先弹一次汇总确认，确认后全部
   关闭、取消则全部不动；无忙碌直接关。
5. 「打开命令行」在该工作区根目录拉起系统终端；远程（SSH）工作区或目录已不存在时
   置灰。「关闭其它所有工作区」只有一张标签时置灰，「关闭所有空闲会话」在该工作区
   没有已打开的空闲对话时置灰。

### US-49 子代理并发上限

作为用户，我希望同一对话里派生的子代理最多 4 个同时运行、超出的自动排队等前面的
完成后再启动，以便 fan-out 任务有确定的资源上界，也不会出现卡死机器的无限并发。

验收标准：

1. 同一父会话同时运行的子代理最多 4 个：一轮内并行发起 ≤ 4 个 `Agent` 调用全部
   立即启动（工具结果形态与排队前一致）；超出上限的调用在工具调用内排队，拿到
   空闲槽位前不创建子代理会话（侧栏不出现新会话）。
2. 任一子代理结束（完成 / 被中止 / 失败）立即释放槽位，最早的排队调用按 FIFO 启动；
   同轮与后续轮次发起的调用共用同一队列，不同父会话之间互不挤占。
3. 排队中的调用属前台查询：中止父会话前台时排队调用全部取消（工具结果为取消
   文案）且不创建会话，已运行的子代理不受首次中止影响（见
   [abort-button.md](abort-button.md) 的三态语义）。
